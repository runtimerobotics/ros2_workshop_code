# Python basics

Everything a ROS 2 Python node uses, without ROS. Run each file with `python3 <file>`.

| File | Shows |
|---|---|
| `01_basics.py` | values, lists, dictionaries, f-strings, loops, `if`, functions |
| `02_classes.py` | classes, `__init__`, methods, inheritance, `super()` (every node is a class like this) |
| `03_callbacks.py` | passing a function to be called later (how subscriptions and timers work) |
| `04_self_check.py` | predict the output, then check `solutions/04_self_check.md` |
| `05_exercise_turtle_path.py` | fill in a function until the checks pass; solution in `solutions/` |
