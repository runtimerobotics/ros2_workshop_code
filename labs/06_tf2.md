# Lab 6: debug the frame tree

**Goal:** read a frame tree, query any transform, and find a broken link from its error.

```bash
ros2 launch demo_tf2 follow.launch.py               # turtle2 follows turtle1
ros2 run turtlesim turtle_teleop_key                # drive turtle1

ros2 run tf2_tools view_frames                      # writes frames_*.pdf
ros2 run tf2_ros tf2_echo turtle2 turtle1
ros2 run tf2_ros tf2_monitor turtle2 turtle1
ros2 run demo_tf2 frame_listener --ros-args -p source:=turtle2
```

Static frames:

```bash
ros2 run demo_tf2 static_frames
ros2 run tf2_ros tf2_echo base_link lidar_link      # 0.1 0 0.2, no rotation
ros2 topic echo /tf_static --qos-durability transient_local
```

Now break it: ask for a frame that does not exist.

```bash
ros2 run tf2_ros tf2_echo turtle3 turtle1           # Invalid frame ID "turtle3" ... frame does not exist
```

**Done when** you can say which node publishes each transform in `view_frames`.

**Challenge:** add a "carrot" frame 1 m behind turtle1 and make turtle2 follow the carrot.
